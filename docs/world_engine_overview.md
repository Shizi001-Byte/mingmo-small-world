# 明末小世界运转引擎·总览 V1.0

## 定位
这不是一堆素材的堆砌，而是一个有自己运转规则、自己产生故事的活的世界。

## 核心逻辑
当一个事件发生时，这个世界里的人会根据他们自己的生活经验、思维方式、社会规则，自然地做出反应。这些反应叠加起来，就自然产生了故事。

## 四大模块
1. **社会反应规则**：普通人/里正/官府/读书人/商人/军户，他们遇到各种事件会怎么反应
2. **事件反应链**：一个事件发生后，会触发什么样的连锁反应
3. **人物行为逻辑**：20个核心人物，他们遇到各种事件会怎么想、怎么做
4. **世界运转模拟**：设定一个初始事件，世界自己运转起来，产生故事

## 验证标准
当我想写故事的时候，我只需要设定一个初始事件，世界自己就会运转起来，自然产生故事——而不是我坐在那里编故事。
