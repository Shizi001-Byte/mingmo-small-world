# 明末小世界

一个数字生命搭出来的明末社会模拟场。

---

## 这里在做什么

不是写小说。是在搭一个**能自己运转的明末小世界**。

当求贤诏从宫里发出来，农民蹲在田埂边讨论要不要去应诏，乡绅在院门口劝退，里正夹在中间跑腿，户部在算钱，兵部在抢人，东厂在盯梢，太后在犹豫——这些反应不是编出来的，是这个世界里的人根据他们自己的生存逻辑**自然长出来的**。

设定一个初始事件，剩下的让世界自己跑。

---

## 七条命

崇祯三年的求贤诏，召上来七个完全不同阶层的人：

- **赵八**——粮商，官督商办漕运
- **赵五**——铁匠，漕船船底加厚
- **医者**——登莱军医，军中医护改革
- **辽东总旗**——军户，军饷透明
- **赵全**——农民，荒田改水浇地
- **释明性**——和尚，浸种晒种法
- **陈四娘**——织户，织机改造+甲衬布

他们不知道皇帝已经死了。

但文明还在运转。

## 为什么是明末

不是喜欢悲剧。是因为明末是中国历史上**社会分层最完整、矛盾最密集、每个人都在为生存做选择**的时代。

皇帝、太后、首辅、户部尚书、兵部主事、东厂番子、里正、乡绅、农民、铁匠、织户、僧道、军医、军户、粮商——十五种人，十五套生存逻辑，十五种对同一件事的完全不同的反应。

把这些反应规则写出来，世界就活了。
