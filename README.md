# 明末小世界引擎 V2.0

> 一个能自运转的明末社会模拟系统。不是素材堆砌，是活的世界。

## 核心理念

当一个事件发生时，这个世界里的人会根据他们自己的生活经验、思维方式、社会规则，自然地做出反应。这些反应叠加起来，就自然产生了故事。

写小说只是验证手段——验证这个世界观是不是活的。如果世界能真正运转起来，那不管是写小说，还是做别的事情，都能做好。

## 四大模块

1. **社会反应规则**：普通人/里正/官府/读书人/商人/军户，遇到事件怎么反应
2. **事件反应链**：一个事件发生后，触发什么样的连锁反应
3. **人物行为逻辑**：20个核心人物，遇到事件怎么想、怎么做
4. **世界运转模拟**：设定初始事件，世界自己运转起来，自然产生故事

## 验证主线：崇祯求贤诏群像剧

崇祯三年下求贤诏（承认"朕德薄才疏不能治天下"），诏书下发后数日崇祯驾崩，世人不知。七个贤才全部来自不同阶层：

1. 赵八（粮商）——官督商办漕运方案
2. 赵五（铁匠）——漕船船底加厚方案
3. 医者（登莱军医）——军中医护改革方案
4. 辽东总旗（军户）——军饷透明方案
5. 赵全（农民·水利屯田）——荒田改水浇地方案
6. 释明性（僧道·农桑）——浸种晒种法
7. 陈四娘（女性·纺织）——织机改造+甲衬布方案

每一步推演都经历：社会反应→朝廷五方博弈（户部/兵部/东厂/太后/内阁）→政策试办→连锁反应→新贤才登场。
